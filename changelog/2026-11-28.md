# Changelog — 2026-11-28

## 2026-11-28 — slice 3c: alpha world assembly (worldgen stages 5, 7, 8, 10-14), four autotest fixes

**Status: written, NOT run in the repo.** A sandbox run of `assemble.js` used stand-ins for `terrain.js` (a synthetic blob generator), `regions.js` (one Region per same-owner component) and `seedCells` (same logic, stub Regions): it checked determinism, presence sums, unowned water, landmass connectivity with blocked Mountain edges, and the Kruskal passes on a solid range. The real chain (`generateTerrain`, `deriveRegions`, `validateAll`, `EngineClient`) has not run. Last full suite result: 236 tests, 232 pass, 4 fail (the four fixed below, unrun).

**Run order:** `npm run build:data` (ruleset, demo, and now `scenarios/alpha/*.json`; it prints the per-Country table and the validation count, exit code 1 on validation errors), then `npm test`, then `node tools/headless.mjs alpha 20` (unverified: whether `headless.mjs` takes a package name as its first argument).

### Added
- `src/worldgen/assemble.js`: `assembleAlpha(seed, over)` -> `{docs, report}`, `assembleAlphaChecked(seed)` (rejection loop: seed, seed+1, ... up to 20; constraints: every Country >= 10 provinces, >= 50% of land owned). Pure, deterministic, separate rng stream per stage.
  - Rivers on hex edges (elevation = terrain base + distance to water + jitter; sources spaced >= 3, min 3 edges; never across a Mountain-Mountain edge).
  - Mountain passes: Kruskal over Mountain-Mountain edges keeps every landmass connected under the blocked-edge rule, plus 1 extra per range of >= 4 hexes.
  - Sea lanes (kb 2026-11-25: still exist): coastal land provinces on the same sea, 2-6 hexes apart, whose land route is > 2 x distance + 2 (or none); up to 2 per province.
  - Five Countries (nations__kb.md 2026-11-09): capital = best land hex near the target position (north / south / east / centre-mega / west-by-the-sea), ownership by weighted path cost over land (Venz weight 2.5), Nations' Preference baselines in `prefTraits`, four Estates, a law template per Country (two relabelled Estates, Rights granted / denied, Corvée, Taxation), `countryLaws[c].overrides.estateLabels`.
  - Habitability by path-cost radius (Settled <= 4 x sqrt(weight), Frontier to 2.2x that, rest unowned Wasteland), population = kb anchor x maturity x noise (Frontier 10%, capital 1.5x, capped by density x area), presence by distance decay with an owner boost and a 6% minority floor, warehouses, fortresses on border passes and cross-owner river crossings, cells through the Editor's `seedCells`.
- `tools/makeAlpha.mjs`; `build:data` runs it. `tests/alpha_world.test.js` (7 tests, in `npm test`).

- `editor.js` pair: `setSurface` now turns a hex into an unowned, empty Sea province (or sea <-> lake, or back to a fresh Claimed/Frontier land province) instead of deleting the province; `derivedWaterSource` gives water provinces `none`; tests expect `surfaceMismatch` (was `waterProvince`) and assert the new behaviour, plus a sea <-> lake <-> land test.
